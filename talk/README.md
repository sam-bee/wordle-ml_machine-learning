The `talk/abstract.md` file contains the abstract of a talk to be done about the project.

The `talk/talk-notes.md` file should contain notes on what will be included in the talk. The talk is to be 1 hour long.
It must be true to the abstract. The audience will be Go developers, often with little prior knowledge of machine
learning. The talk notes will be used to produce slides for the talk, so they should be structured, sequenced etc. in a
way that makes sense.
